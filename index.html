Import leads (CSV)

Expected columns: Name, PAN, Mobile No, Email, DOB, Annual Income Range, Company, ICI Cr Lmt, Address. Only Mobile No is required — a row with just a number still imports, and shows to the agent as Name not provided. DOB must be DD-MM-YYYY; Address is capped at 2000 characters and is truncated past that. Give the batch a name so you can report on it later.

Create agent
