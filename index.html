App versions

What each agent's phone last reported on launch — this app is sideloaded, so this is the only way to know who has actually updated. Blank means that phone has never run a build new enough to report it (v1.7.1 or later). Device is reported from v1.8.2 — an agent still on an older build shows blank here even once their version updates, until they relaunch once more. Device ID (from v1.9.4) is per-install and stable across relaunches, unlike Device which is just a model name shared by every unit of that model — two agents showing the same Device ID in red really are on the same physical phone, not just the same phone model. Archive an agent who has left — they immediately lose the ability to sign in or place calls, and any lead still assigned to them goes back to the pool for someone else to claim. Archived agents move to their own page (button above) instead of cluttering this list; unarchiving from there is reversible any time.

Import leads (CSV)

Expected columns: Name, PAN, Mobile No, Email, DOB, Annual Income Range, Company, ICI Cr Lmt, Address. Only Mobile No is required — a row with just a number still imports, and shows to the agent as Name not provided. DOB must be DD-MM-YYYY; Address is capped at 2000 characters and is truncated past that. Give the batch a name so you can report on it later.

Create agent

Login ID and password only. There is no email step for you or the agent — the address Supabase needs underneath is built and used automatically, and only that server-side function ever sees it.

Manage agent assignments

A manager sees reports only for the agents checked here — nothing is visible to a manager until at least one agent is assigned. Admin accounts always see everyone regardless of this list.

Archived agents

Agents archived from the App versions page. They can no longer sign in or place calls; any lead that was still assigned to them was released back to the pool at the moment they were archived. Unarchive to let them work again — they start claiming fresh leads, nothing old is handed back automatically.
